# Changelog

## [0.1.1]

- Add instant window and monitor capture shortcuts on X11, including monitor selection under the pointer.
- Show window and screen shortcut settings on X11.
- X11 instant capture support is implemented but not yet tested in an X11 desktop session.

## [0.1.0]

- Screenshot capture, library and editor for X11 and GNOME Wayland.
- Optional evdev fallback for global shortcuts.
- Signed AppImage updates with progress, recovery copy and explicit restart.

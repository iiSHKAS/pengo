يجمع Pengo التقاط الشاشة ومكتبة الصور ومحرّر التعليقات في برنامج واحد. يمكنك تصوير منطقة أو نافذة، وإضافة الأسهم والنصوص، ثم حفظ الصورة والرجوع إليها من المكتبة. يدعم البرنامج العربية والإنجليزية، واتجاه العرض من اليمين إلى اليسار، والمظهرين الفاتح والداكن.

## المميزات

- **التقاط الشاشة:** تحديد منطقة أو نافذة على X11 وقنوم Wayland، مع اختصارين إضافيين في قنوم لتصوير النافذة أو الشاشة تحت مؤشر الماوس مباشرة.
- **التعديل والتوضيح:** نصوص وأسهم وأشكال وخطوات مرقّمة ورسم حر وتظليل، مع أدوات القص والتمويه والبكسلة.
- **مكتبة الصور:** عرض مصغّرات الصور، والبحث والفرز والمفضلة وإعادة التسمية وفتح موقع الملف.
- **الحفظ والنسخ:** صيغ PNG وJPG وWebP وBMP، والتحكم بجودة JPEG، والنسخ إلى الحافظة.
- **العمل في الخلفية:** اختصارات عامة قابلة للتعديل، والتشغيل مع النظام، والإخفاء في شريط النظام عند توفره.
- **التحديثات:** تنزيل تحديثات AppImage الموقّعة وتثبيتها، مع ترك قرار إعادة التشغيل لك.

## دعم سطح المكتب

| الجلسة | تصوير الشاشة | الاختصارات العامة |
|---|---|---|
| X11 | مدعوم عبر محرك X11 | تسجيل الاختصارات الأصلي |
| قنوم على Wayland | مدعوم عبر إضافة WinProbe المرفقة | اختصارات قنوم المخصصة |
| واجهات Wayland الأخرى | غير مدعوم حاليًا؛ تبقى المكتبة والمحرّر متاحين | بديل evdev اختياري |

بديل **evdev** يغيّر طريقة استقبال الاختصارات فقط، ولا يضيف دعم تصوير لواجهات Wayland الأخرى. تفعيله يتطلب موافقتك، وقد يطلب النظام تفويض المسؤول لمنح صلاحية قراءة لوحة المفاتيح. التفاصيل في [دليل الاختصارات](docs/shortcut-fallback.md).

## تشغيل AppImage

نزّل `Pengo.AppImage` من أحد [الإصدارات المنشورة](https://github.com/iiSHKAS/pengo/releases)، ثم نفّذ:

```sh
chmod +x Pengo.AppImage
./Pengo.AppImage
```

على **قنوم Wayland**، افتح الإعدادات وثبّت إضافة التصوير. قد تحتاج إلى تسجيل الخروج والدخول مرة واحدة عند تثبيتها لأول مرة. تعرض الإعدادات حالة اتصال البرنامج بمحرك التصوير.

### الاختصارات الافتراضية

| الاختصار | الوظيفة | التوفر |
|---|---|---|
| `Ctrl+Shift+E` | فتح تحديد الالتقاط | X11 وقنوم Wayland |
| `Ctrl+Alt+W` | تصوير النافذة تحت المؤشر | قنوم Wayland |
| `Ctrl+Alt+S` | تصوير الشاشة تحت المؤشر | قنوم Wayland |

يمكن تغييرها من **الإعدادات ← الاختصار**، أو بدء الالتقاط من البرنامج وقائمة شريط النظام.

## التحديثات

التحديث التلقائي مفعّل افتراضيًا لنسخة AppImage. يبدأ الفحص بعد 30 ثانية، ثم يتكرر كل ست ساعات أثناء التشغيل. يتحقق البرنامج من توقيع الملف ورقم إصداره الموقّع، ويحفظ نسخة احتياطية بامتداد `.previous` قبل استبدال AppImage.

لا يعيد Pengo تشغيل نفسه تلقائيًا. يمكنك اختيار إعادة التشغيل أو استخدام الإصدار الجديد عند فتح البرنامج لاحقًا. تتيح الإعدادات تعطيل التحديث التلقائي أو إجراء فحص يدوي. نسخة التطوير والملف التنفيذي العادي لا يدعمان التحديث الذاتي.

راجع [دليل التحديث والبناء والنشر](docs/updates.md). اسم الإصدار ووسم GitHub رقميان مثل `0.1.0` دون بادئة `v`.

## التشغيل من المصدر

يتكوّن البرنامج من خلفية **Rust وTauri 2** وواجهة HTML وCSS وJavaScript. بعد تثبيت Rust واعتماديات Tauri على Linux، نفّذ الأوامر التالية بالتتابع:

```sh
git clone https://github.com/iiSHKAS/pengo.git Pengo
cd Pengo
cargo run --manifest-path src-tauri/Cargo.toml
```

تحتاج أدوات اختبارات JavaScript وتجهيز AppImage إلى Node.js 22 وتنفيذ `npm ci`. تتوفر تفاصيل الاعتماديات وبنية المشروع في [دليل التطوير](docs/development.md).

## المصدر والترخيص

تتضمن آلية اختصارات قنوم وبديل evdev ونظام التحديث كودًا مقتبسًا من **Sonux / Mixweave**. تحتفظ إضافة التصوير بهوية WinProbe للتوافق.

المكوّنات المنقولة من Sonux / Mixweave مرخّصة تحت **GPL-3.0-only**، والنص محفوظ في [ملف الترخيص](licenses/Sonux-GPL-3.0.txt). تحتفظ الاعتماديات بتراخيص مشاريعها الأصلية.
